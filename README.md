# 🚀 Jenkins DevOps Assignments

## 📌 Overview

This repository contains a series of DevOps assignments focused on learning and implementing Continuous Integration and Continuous Deployment (CI/CD) using Jenkins.

The assignments cover Jenkins installation, job creation, GitHub integration, automated builds, and pipeline creation.

---

## 🛠️ Tools & Technologies

* Jenkins
* Git & GitHub
* Java (JDK 17+)
* Apache Maven
* Web Browser (Chrome/Firefox)

---

## 📚 Assignments Included

### 🔹 Assignment 1: Jenkins Installation & Architecture

* Studied CI/CD concepts and Jenkins architecture
* Understood master-agent architecture and plugins
* Installed Jenkins and configured initial setup

---

### 🔹 Assignment 2: Freestyle Job

* Created a Freestyle job in Jenkins
* Executed a simple build command (`Hello, Jenkins!`)
* Viewed console output logs

---

### 🔹 Assignment 3: Jenkins + GitHub Integration

* Integrated Jenkins with GitHub repository
* Configured Jenkins to pull source code
* Used plugins and webhooks for automation

---

### 🔹 Assignment 4: CI Job with Build Trigger & Pipeline

* Created a Jenkins job to compile a Java project
* Configured **Poll SCM trigger** for automatic builds
* Implemented Jenkins Pipeline with stages:

  * Build
  * Test
  * Deploy
* Used Jenkinsfile for pipeline as code

---

## ⚙️ Key Concepts Learned

* Continuous Integration (CI) & Continuous Deployment (CD)
* Jenkins Architecture (Master-Agent)
* Freestyle vs Pipeline Jobs
* GitHub Integration with Jenkins
* Automated Build Triggers
* Pipeline as Code (Jenkinsfile)

---

## ▶️ How to Run

1. Install Jenkins and Java
2. Start Jenkins server (`http://localhost:8080`)
3. Create jobs (Freestyle / Pipeline)
4. Connect GitHub repository
5. Run builds and monitor console output
